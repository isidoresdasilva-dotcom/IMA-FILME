I.M.A FILMES V10.1 — versão profissional

Arquivos:
- index.html
- style.css
- app.js
- config.js

Instalação no GitHub:
1. Abra o repositório IMA-FILME.
2. Substitua index.html, style.css e app.js.
3. Envie config.js junto.
4. Faça Commit changes.
5. Aguarde o GitHub Pages atualizar.

Supabase:
- A configuração pública está em config.js.
- Não coloque service_role, senha do banco ou qualquer chave secreta no frontend.

Importante:
- Os buckets videos e ebooks podem ser privados; o app usa signed URLs para vídeos.
- URLs blob: antigas não são usadas como URLs permanentes.
- Se o navegador continuar mostrando erros blob antigos, faça um recarregamento forte (Ctrl+Shift+R) e limpe os dados do site do GitHub Pages uma vez.
