# I.M.A FILMES V9 — Supabase
1. Crie um projeto no Supabase.
2. Abra SQL Editor e execute `schema.sql`.
3. Em Project Settings > API copie Project URL e anon public key.
4. Coloque esses valores em `config.js`.
5. Não use `service_role` no navegador.
6. Em Authentication > Providers deixe Email habilitado.
7. Publique a pasta no GitHub Pages.

A V9 usa Supabase quando as credenciais são válidas. Sem credenciais, continua em modo local para testes.
